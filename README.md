### I build privacy & security tools.

Right now that's **[SWIVEL](https://github.com/officialtomblack/SWIVEL)** — a passive Wi-Fi & Bluetooth scanner for Android that flags nearby cameras, trackers, and surveillance gear. Receive-only, fully offline, no accounts.

**Stack:** Android · BLE / Wi-Fi RF · ESP32 — with a bias toward keeping data off other people's servers.
